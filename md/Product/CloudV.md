## 02 Why Softworks

**소프트웍스가 CloudV를 다루는 방식**

### Why 01 — 까다로운 보안 규격, 소프트웍스의 독자적 기술력으로 돌파했습니다

외산 가상화 솔루션이 해결하기 힘든 소스코드 제출, 취약점 조치, 규정 수정 등의 보안 요건을 충족하기 위해, 소프트웍스는 인증이 가능한 범위 안에서 직접 가상화 포털을 설계 · 개발했습니다. 공공 · 금융의 자원 관리 편의성은 높이고 보안기능확인서와 조달 등록으로 신뢰를 더한 CloudV, 검증된 국산 포털 기술의 차이를 경험해 보세요.

![사용자 포털(CloudV)과 가상화 엔진(VM Essentials), 그 아래 HVM 클러스터로 이어지는 구성](assets/cloudv/dia-cloudv.svg)
*사용자 포털(CloudV)과 가상화 엔진(VM Essentials), 그 아래 HVM 클러스터로 이어지는 구성*

### Why 02 — 인프라부터 포털까지, 단일 창구가 책임지는 일체형 서비스를 제공합니다

가상화 엔진 구축과 사용자 포털 개발을 서로 다른 사업자가 담당하면, API 연동 문제나 장애가 발생했을 때 책임 소재가 불분명해지기 쉽습니다. 소프트웍스는 HPE VM Essentials 인프라 구축부터 CloudV 포털 연동까지 전 과정을 하나의 전담 팀이 일괄 수행합니다. 불필요한 소통 지연이나 책임 전가 없이, 단일 창구를 통한 신속하고 완벽한 기술 지원을 제공합니다.

### Why 03 — 신청부터 할당까지, 프로세스 자동화로 간편해집니다

이메일과 엑셀로 번거롭게 오가던 자원 신청 및 복잡한 할당 절차가 CloudV 포털의 자동화 워크플로우로 한층 쉬워집니다. 표준화된 명명 규칙, 사전 정의된 자원 사양, 승인된 템플릿 이미지를 기반으로 신청부터 승인 · 생성 · 할당까지 자동으로 연동되어, 관리자의 개입을 최소화하면서도 빠르고 정확하게 자원을 제공합니다.

![신청에서 할당까지의 흐름과 각 단계에서 관리자가 쥐고 있는 통제 지점](assets/cloudv/dia-cvflow.svg)
*신청에서 할당까지의 흐름과 각 단계에서 관리자가 쥐고 있는 통제 지점*

### Why 04 — 고객사의 환경과 요구사항에 맞춘 유연한 커스터마이징을 제공합니다

독자적인 원천 기술과 포털 소스코드를 보유하고 있어, 고객사의 기존 계정 체계, 전자결재 연동, 특화된 보안 정책에 맞춰 화면과 기능을 맞춤 설계합니다. 패키지 제품에 조직의 프로세스를 맞추는 불편함 없이, 고객사의 요구사항에 제품을 유연하게 맞춰 가장 효율적인 가상화 운영 환경을 완성합니다. 이렇게 실제로 구현한 범위는 아래 확장 기능에 정리했습니다.

![요건에 맞춰 구성한 통합 대시보드 — 운영 요약과 클러스터 자원 사용, 물리 서버 상태를 한 화면에 둔 구성](assets/cloudv/cv-dashboard.png)
*요건에 맞춰 구성한 통합 대시보드 — 운영 요약과 클러스터 자원 사용, 물리 서버 상태를 한 화면에 둔 구성*

| **Design** | HVM 클러스터 구성 설계 · 자원 수명 주기와 회수 정책 설계 · 신청 · 승인 흐름과 역할 설계 · 포털 설치 구성과 연동 구간 설계 · 보안 요구사항 반영 설계 |
| **Build** | HPE VM Essentials 구축 및 클러스터 구성 · CloudV 포털 설치 (컨테이너 기반) · 인증 · 계정 연동 · 성능 검증 |
| **Migrate** | 대상 워크로드 이전 · 업무 단위 전환 · 단계별 전환 계획 및 롤백 기준 |
| **Operate** | 포털 운영 지원 · 기능 추가 개발 · 버전 · 패치 공급 · 인증 갱신 대응 |

## 04 Knowledge Base

**HPE VM Essentials 연동 기술과 구축 경험이 곧 우리의 자산입니다**

가상화 엔진과 사용자 포털을 원활하게 연동하고 안정적으로 운용하는 것은 오직 실전 경험을 통해서만 얻을 수 있는 고유한 기술력입니다. 소프트웍스는 HPE VM Essentials의 API 구조를 깊이 이해하고 CloudV 포털과의 최적화 연동을 직접 설계 · 구현했습니다. 어떤 기능과 워크플로우가 실제 현장에 필요한지, 자원 할당과 거버넌스를 어떻게 매끄럽게 연결해야 하는지 이미 노하우를 확보하고 있기에 시행착오 없는 구축을 수행합니다.

| 지표 | 내용 |
|---|---|
| **공공기관 구축** | 공공 분야 실구축 레퍼런스 보유 |
| **제품 개발** | 분석 · 설계 · 개발 · 배포 전 과정 자체 수행 |
| **보안인증** | 시험 수검과 지적사항 조치까지 직접 경험 |
| **조달 등록 완료** | 기술 문서 · 저작권 등록 · MAS 절차까지 직접 수행 |

**축적된 자산**

- HPE VM Essentials API 연동 표준 아키텍처 — 자원 할당 · 상태 동기화 · 제어 모듈 라이브러리
- 포털 설치 표준 구성 패키지 — 컨테이너 · OS · 런타임 환경의 단일화된 배포 스크립트
- 신청 · 승인 워크플로우 설계 패턴 — 업무 흐름별 표준 승인 및 자원 프로비저닝 자동화 패턴
- 역할 및 권한 기반 화면 설계 기준 (RBAC) — 관리자 · 부서장 · 사용자별 기능 · 자원 접근 권한 표준
- 계정 연동 인터페이스 정의서 — LDAP · AD, SSO, 사내 계정 시스템 연동 표준 양식
- 감사 로그 표준 규격 — 자원 변경, 접근 이력, 승인 내역 추적을 위한 로그 프레임워크
- 보안인증 대상 기능 범위 선정 기준
- 인증 제출 문서 세트 (기능 명세 · 오픈소스 목록 · 조치 내역)

## 05 Field Issues

| 현장에서 생기는 문제 | 소프트웍스의 해법 |
|---|---|
| “사용하려는 가상화 제품이 보안인증이 없어 도입이 어렵습니다” | CloudV는 까다로운 공공 · 금융 보안 요건을 충족하여 국가 보안기능확인서를 정식으로 취득한 가상화 관리 포털입니다. 검증된 보안 안정성을 바탕으로 조달 등록까지 완료되어, 복잡한 인증 절차나 보안 우려 없이 즉시 조달을 통해 안심하고 도입하여 운용하실 수 있습니다 |
| “솔루션은 선정하였으나 관리자와 사용자의 역할을 분리하고 싶습니다” | 가상화 엔진의 표준 관리 콘솔만으로는 현업의 자유로운 이용과 관리자의 효율적인 통제를 동시에 충족하기 어렵습니다. CloudV는 사용자 포털과 관리자 포털을 명확히 분리하여 제공합니다. 현업 사용자는 직관적인 화면에서 필요한 자원을 손쉽게 신청 · 이용하고, 관리자는 승인 · 거버넌스 · 전체 자원 통제에 집중할 수 있어 역할에 최적화된 업무 환경을 완성합니다 |
| “VM 신청을 매번 메일과 엑셀로 받다 보니 비효율적입니다” | 자원 요청부터 수동 생성, 할당 전달까지 이어지던 비효율적인 운영 업무를 자동화했습니다. 신청 → 승인 → 자동 생성 → 자원 할당으로 이어지는 일련의 흐름이 포털 내에서 매끄럽게 연결됩니다. 담당자의 단순 반복 업무 부담은 대폭 줄어들고, 현업은 필요한 인프라를 지연 없이 즉시 제공받아 사용할 수 있습니다 |
| “누가 언제 무엇을 했는지 이력 관리가 되지 않습니다” | 누구에 의해, 언제, 어떤 자원이 변경되었는지 한눈에 파악할 수 있는 강력한 감사 기능을 제공합니다. 위변조가 불가능한 안전한 기록 보관 구조와 기관 맞춤형 로그 관리 정책을 통해, 내부 보안 점검과 규제 대응에 완벽히 대비할 수 있습니다 |
| “포털과 기관에서 사용하는 계정 체계가 맞지 않아 불편합니다” | 기관 및 기업에서 이미 사용 중인 인사 체계와 계정 관리 시스템을 그대로 연동할 수 있습니다. 표준 프로토콜 연동을 통한 실시간 계정 동기화는 물론, 사내 인사 시스템의 조직 · 권한 코드를 CloudV 포털의 역할(Role)로 자동 매핑합니다. 별도의 수동 계정 관리 없이 로그인부터 화면 권한 제어까지 일원화되어, 더욱 편리하고 안전한 통합 운영 환경을 제공합니다 |
| “장기간 미사용 가상 머신이 계속 쌓입니다” | 장기간 전원이 꺼져 있거나 사용률이 기준치 아래인 유휴 VM, 종료된 프로젝트의 자원을 시스템이 스스로 찾아냅니다. 소유자에게 자동으로 알림을 전송하여 연장 또는 반납을 간편하게 선택할 수 있게 돕고, 확인된 자원은 안전하게 회수하여 이력까지 투명하게 남깁니다 |

## 06 CloudV 구성요소 — CloudV를 이루는 세 가지 구성요소

사용자와 관리자 각각의 역할에 최적화된 포털 화면을 통해, 인프라 자원 신청부터 승인, 할당, 모니터링까지 이어지는 전체 관리 구간과 소프트웍스만의 주요 적용 항목을 실제 화면으로 확인해 보세요.

### 셀프서비스 포털 — 클릭 몇 번으로 끝내는 VM 신청과 관리를 제공합니다

인프라 신청부터 사용까지, 더 이상 복잡한 절차나 수작업을 거칠 필요가 없습니다. 사용자가 포털에서 직접 가상 머신을 신청하고, 승인 후 자동으로 처리되는 스마트한 워크플로우를 경험해 보세요. 생성된 VM의 전원 제어, 스냅샷, 콘솔 접속까지 사용자가 직접 손쉽게 제어할 수 있어 업무 속도와 편의가 획기적으로 향상됩니다.

![골든 이미지와 사양, 수량, 명명 규칙을 골라 한 번에 신청하는 화면](assets/cloudv/cv-request.png)
*골든 이미지와 사양, 수량, 명명 규칙을 골라 한 번에 신청하는 화면*

**소프트웍스가 하는 일** — 기존에 사용하시던 사내 결재 라인을 CloudV 포털 내에 그대로 적용합니다. 사용자가 직접 처리할 수 있는 셀프서비스 범위(전원 제어 등)와 관리자 승인이 필요한 자원 신청 범위를 정교하게 나누어 설계합니다. 이를 통해 불필요한 결재 대기 시간은 줄이고, 관리자의 운영 부담 없는 효율적인 거버넌스를 완성합니다.

### 자원 수명 주기 및 스마트 관리 — 자원 생성부터 운용, 회수까지 완벽히 제어합니다

가상 머신 생성 이후 필요한 모든 관리와 수명 주기 관리를 포털 하나로 처리합니다. VM 사양 변경, 스냅샷 생성 및 복구, 호스트 간 마이그레이션, 콘솔 직접 접속 등 운용에 필요한 핵심 자원 관리 기능을 제공하며, 더 이상 사용하지 않는 자원은 안전하게 반납 및 회수하여 전체 자원의 효율성을 높입니다.

![가상 머신을 만든 뒤에 일어나는 일과, 사용자가 직접 하는 구간 · 승인을 거치는 구간의 경계](assets/cloudv/dia-cvlife.svg)
*가상 머신을 만든 뒤에 일어나는 일과, 사용자가 직접 하는 구간 · 승인을 거치는 구간의 경계*

**소프트웍스가 하는 일** — 단순히 포털 프로그램을 설치하는 데 그치지 않습니다. 구축 과정에서 고객사와 긴밀하게 협력하여 사용자가 직접 처리할 범위와 필수 승인을 거칠 범위를 명확히 나누고, 실효성 있는 유휴 자원 회수 기준을 포털 프로세스 안에 함께 설계합니다. 프로그램과 운영 규칙이 결합된 스마트한 거버넌스로, 방치되는 자원 없는 효율적인 인프라 순환 환경을 완성합니다.

### 보안기능확인서 획득 — 신뢰할 수 있는 보안 · 감사 체계를 제공합니다

공공 · 금융 기관이 안심하고 도입할 수 있도록, CloudV는 보안기능확인서를 취득한 검증된 보안 체계를 갖추고 있습니다. 담당자 역할에 따른 철저한 권한 통제부터 데이터 구간 암호화, 안전한 세션 관리, 그리고 누가 언제 무엇을 했는지 낱낱이 기록하는 행위 단위 감사 로그까지 지원합니다. 인증받은 기능 범위와 적용 버전은 공식 문서로 투명하게 제공하므로, 규정 준수부터 보안 감사까지 걱정 없이 시스템을 운용할 수 있습니다.

![행위 단위로 남는 감사 로그와 무결성 검증 화면](assets/cloudv/cv-audit.png)
*행위 단위로 남는 감사 로그와 무결성 검증 화면*

**소프트웍스가 하는 일** — 기관의 보안 규정 조항을 포털 설정에 맞춰 동기화합니다. 누락된 요건의 개발 반영, 규정 맞춤형 기능 비활성화(기본값) 설정을 거쳐 검증된 상태로 인수인계하므로, 별도의 복잡한 보안 조치 없이 즉시 서비스를 운용할 수 있습니다.

## 08 Operation & Support

**개발한 조직이 직접 지원합니다 — 장애 대응부터 고도화까지 일원화된 원스톱 지원**

CloudV는 소프트웍스가 독자 개발한 솔루션인 만큼, 제품 개발 조직과 기술 지원 조직이 완벽하게 일치합니다. 외부 외주사나 복잡한 유통 단계를 거치지 않기 때문에, 장애 발생 시 원인 분석부터 신속한 복구까지 지연 없는 다이렉트 대응이 가능합니다. 새로운 기능 추가나 커스터마이징 요구사항 역시 개발 담당에게 직접 전달되어 가장 빠르고 정확하게 처리됩니다.

- 포털 운영 지원 및 장애 1차 분석
- 요건에 따른 기능 추가 개발
- 버전 · 패치 공급과 적용 지원
- 보안인증 갱신 및 범위 변경 대응
- 가상화 엔진 제조사 기술 지원 연계
