## 02 Field Issues

**GPU 인프라 운영에서 반복되는 6가지 문제**

GPU가 부족한지 판단하기 전에, 지금 가진 GPU가 어떻게 구축되고 어떻게 나뉘어 있는지부터 봅니다.

| 현장에서 생기는 문제 | GenWorks의 답 |
|---|---|
| 클러스터 하나를 구축하는 데 열흘이 걸린다 | BMC로 서버의 OS 설치부터 초기 설정까지 자동화하고, Zone 용도에 맞는 Slurm·Kubernetes 환경을 자동으로 구성합니다. |
| 부서별 GPU 배분을 엑셀과 구두 합의로 관리한다 | 조직×Zone 단위 계약으로 배분을 시스템에 등록합니다. 쿼터·기간·정책이 계약 조건 그대로 반영되고, 갱신과 만료까지 추적됩니다. |
| 부서마다 노드를 나눠 두어 한쪽은 놀고 한쪽은 기다린다 | 노드를 부서별로 고정 분할하지 않습니다. 각 부서의 몫은 쿼터·우선순위·선점으로 보장하고, 유휴 자원은 다른 부서가 초과 사용합니다. |
| 학습이 끝나 추론 수요가 늘어도 환경을 바꾸기 어렵다 | 운영 중에 Zone 구성을 바꿉니다. 실행 중인 워크로드를 내리지 않고 학습 Zone의 자원을 추론 Zone으로 옮깁니다. |
| 장애가 나면 사람이 원인을 찾아 복구한다 | GPU·Kubernetes·Slurm을 상시 헬스 체크하고, 정책에 따라 재시작·리셋·격리를 자동으로 수행합니다. |
| 연구자의 모든 요청이 운영자를 거쳐야 한다 | 연구자 전용 셀프서비스 콘솔에서 작업 공간 생성부터 학습·서빙·사용량 확인까지 직접 수행합니다. 쿼터와 정책은 화면과 제출 폼에 자동 반영됩니다. |

## 04 Architecture

**공급 – 계약 – 수요를 잇는 자원 모델**

인프라(공급)와 조직(수요)을 계약(배분)으로 연결해 GPU 자원을 체계적으로 관리합니다. 계약 조건을 바꾸면 자원 할당과 운영 환경에 바로 반영됩니다.

### 공급 · Supply — Zone
균질한 GPU 노드 풀 · 파티션. 단일 GPU 모델로 구성하고, 공용/전용 × 용도(Training·Inference)로 분류합니다. Cluster Management가 생성·구성합니다.

### 연결 · Contract — 배분
조직×Zone의 자원 사용권. 쿼터·기간·정책이 계약 조건 그대로 시스템에 반영되며, 쿼터형(공용)과 노드 지정형(전용) 두 방식이 있습니다. Workload Management가 관리합니다.

### 수요 · Demand — 조직
부서 · 프로젝트 · 사용자. 멤버의 그릇이자 배분을 받는 단위이며, 프로젝트 단위로 작업과 자산을 묶습니다. System Administration이 LDAP과 연동해 관리합니다.

> **통제 원칙** — 노드를 부서별로 고정 분할하지 않습니다. 통제는 쿼터·우선순위·선점으로, 보장은 배분 단위의 예외(전용 Zone)로 합니다. 각 부서의 몫은 선점으로 확보하면서 유휴 자원은 다른 부서가 초과 사용할 수 있어 가동률이 유지됩니다.

#### 용도에 따라 나누는 세 가지 Zone

| 항목 | 내용 |
|---|---|
| **Training** | 공용 × AI 모델 학습. 대규모 배치 학습에 최적화된 공용 Zone으로, 쿼터형 배분으로 여러 조직이 공정하게 나눠 씁니다. |
| **Inference** | 공용 × AI 추론 서비스. 상주 서빙 워크로드를 위한 공용 Zone으로, 엔드포인트 단위의 추론 서비스가 배포됩니다. |
| **Dedicated** | 전용 × 단독 할당. 특정 팀·용도에 노드 단위로 단독 할당합니다. 물리적 전용이 계약 요건인 경우를 지원합니다. |

## 05 Provisioning

**고객 환경에 맞춰 유연하게 구성하고 확장합니다**

Zone의 용도에 맞춰 소프트웨어 환경을 자동으로 구성합니다. 별도 구축 작업 없이 학습·추론·전용 Zone을 만들고, 운영 중에 다시 구성하고, 필요한 만큼 확장합니다.

*Zone Provisioning — Zone별 프로비저닝 현황과 노드 단위 Worker 확장을 한 화면에서 관리합니다.*

| 번호 | 항목 | 내용 |
|---|---|---|
| 01 · 구축 | **OS 자동 설치** | BMC를 활용해 서버의 OS 설치부터 초기 설정까지 자동화하여 클러스터 구축 시간을 단축합니다. |
| 02 · 구성 | **자동 프로비저닝** | Zone 용도에 맞는 소프트웨어(Slurm·Kubernetes) 환경을 자동으로 구성하고 프로비저닝합니다. |
