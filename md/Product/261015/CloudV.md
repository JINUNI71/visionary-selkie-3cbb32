## 01 HERO

> **레거시부터 퍼블릭까지,**
> **모든 클라우드를 한 플랫폼에서 관리합니다**
>
> CloudV는 민첩성과 효율성, 셀프 서비스 프로비저닝 엔진을 갖춘 클라우드 관리 플랫폼(CMP)입니다. 온프레미스 프라이빗 클라우드를 빠르게 배포하고, 퍼블릭 클라우드 관리를 한곳으로 모으고, Kubernetes 클러스터 구축과 자동화 작업까지 한 플랫폼에서 수행합니다.

**KEY SUMMARY** — All that & All in One CMP · Powered by Morpheus · Hybrid·Multi Cloud와 DevOps 기술 100여 개 사전 연동 · 보안기능확인서 획득

## 02 Field Issues

**클라우드가 늘수록 반복되는 6가지 문제**

가상화와 프라이빗·퍼블릭 클라우드가 섞일수록 관리 도구와 운영 방식도 갈라집니다.

| 현장에서 생기는 문제 | CloudV의 답 |
|---|---|
| 클라우드마다 관리 도구가 따로 있다 | 레거시·프라이빗·퍼블릭·하이브리드·멀티 클라우드를 하나의 플랫폼에서 관리하고, 운영 환경을 표준화합니다. |
| 관리 도구가 특정 가상화 제품에 묶여 있다 | VMware · Nutanix · Microsoft 등 여러 하이퍼바이저와 프라이빗 클라우드를 함께 지원합니다. |
| 퍼블릭 클라우드는 관리 툴과 빌링 툴이 따로 논다 | 글로벌·국내 퍼블릭 클라우드를 함께 관리하고, 상세 보고·비교·권장 사항을 담은 Chargeback으로 비용을 한곳에서 봅니다. |
| 컨테이너 환경은 별도로 개발해야 한다 | Docker · Swarm · Kubernetes를 기본 지원해 Kubernetes 클러스터를 쉽게 구축합니다. |
| 자원을 하나 받으려면 요청과 승인을 사람이 처리한다 | 셀프 서비스로 사용자가 직접 자원을 요청하고, 모든 클라우드에서 자동화 워크플로우를 실행합니다. |
| 기능이 필요할 때마다 추가 개발이나 별도 제품 구매가 필요하다 | Jenkins · GitHub 등 대부분의 도구와 사전 연동되어 있고, 정기적인 Major·Minor 업그레이드로 기능이 계속 더해집니다. |

## 03 Why CloudV

**클라우드 관리 영역 전체를 하나의 플랫폼으로**

가트너가 제시한 클라우드 관리 툴킷은 관리 영역을 여덟 가지 필수 기능으로 나눕니다. 이 영역을 모두 아우르는 CMP가 있어야 조직은 프라이빗과 퍼블릭을 넘나드는 멀티 클라우드 서비스와 자원을 제대로 관리할 수 있습니다.

### 01 — 8개 관리 영역을 모두 제공합니다
서비스 요청부터 패키징·딜리버리까지 가트너 관리 툴킷의 8개 영역을 모두 제공하는 CMP입니다.

### 02 — 셀프 서비스로 속도를 높입니다
셀프 서비스 기능으로 비즈니스 민첩성을 높이고 가치를 만드는 시간을 줄입니다.

### 03 — 운영 환경을 표준화합니다
온프레미스 프라이빗 클라우드에 퍼블릭 클라우드 하이퍼스케일러 수준의 기능을 제공하고, 운영 환경을 표준화합니다.

### 04 — 거버넌스를 하나로 묶습니다
거버넌스 모델을 통합해 운영 복잡성을 줄입니다.

### 05 — 모든 클라우드에서 자동화합니다
어느 클라우드에서든 같은 자동화 워크플로우를 실행합니다.

## 04 Key Capabilities

**클라우드 관리의 8개 영역**

거버넌스·라이프사이클 관리·중개·자동화에 걸친 여덟 가지 필수 기능 영역을 한 플랫폼에서 다룹니다.

| 항목 | 구분 | 내용 |
|---|---|---|
| **Service Request** | 서비스 요청 | 사용자가 셀프 서비스로 필요한 자원과 서비스를 직접 요청합니다. |
| **Provisioning & Orchestration** | 프로비저닝 · 오케스트레이션 | 프라이빗·퍼블릭 클라우드와 컨테이너 환경을 배포하고 자동화 워크플로우를 실행합니다. |
| **Cost Management & Resource Optimisation** | 비용 관리 · 자원 최적화 | 상세 보고와 비교, 권장 사항을 담은 Chargeback으로 비용을 관리합니다. |
| **Cloud Migration, Backup and DR** | 마이그레이션 · 백업 · 재해복구 | Veeam · Commvault · Zerto 등 데이터 보호 제품과 연동합니다. |
| **Identity, Security & Compliance** | 인증 · 보안 · 컴플라이언스 | Active Directory · Okta · SAML과 연동하고, 거버넌스 모델을 통합합니다. |
| **Inventory & Classification** | 인벤토리 · 분류 | 실시간 환경 인벤토리를 유지하고, 변경된 시스템을 찾아 갱신합니다. |
| **Monitoring & Analytics** | 모니터링 · 분석 | 상세한 작업 보고와 가동시간 관리를 제공하고, 모니터링·로깅 도구와 연동합니다. |
| **Packaging & Delivery** | 패키징 · 딜리버리 | Jenkins · GitHub · Packer 등 CI/CD 도구와 연동해 애플리케이션 배포까지 이어갑니다. |

## 06 Comparison

**솔루션형 CMP와 개발형 CMP의 차이**

CloudV는 검증된 CMP 엔진 위에 구성한 솔루션형 CMP입니다. 요구사항마다 개발로 채우는 개발형 CMP와 비교했습니다.

| 항목 | 솔루션형 CMP · CloudV | 개발형 CMP |
|---|---|---|
| **라이선스** | 인스턴스 수에 따라 과금 | 제조사별로 상이 |
| **가상화 · 프라이빗 클라우드** | 모두 지원 | 단일 가상화 제품 지원 (VMware 또는 OpenStack) |
| **퍼블릭 클라우드** | 글로벌 · 국내 퍼블릭 클라우드 지원 | 제한적 지원, 관리 툴과 빌링 툴로 이원화된 운영 |
| **컨테이너** | Docker · Swarm · Kubernetes 기본 지원 | 미지원, 별도 개발 필요 |
| **Chargeback** | 상세 보고 · 비교 · 권장 사항, 사용자 정의 데이터 추출을 위한 전체 문서화 API | 일부 지원 (MSP 제공 CMP는 별도 툴 구매 필요) |
| **Governance** | 실시간 환경 인벤토리 · 변경 시스템 검색 갱신 · 상세 작업 보고 · 멀티 테넌시 · 가동시간 관리 | 일부 지원 |
| **DevOps** | Jenkins · GitHub 연동, 대부분의 애플리케이션 지원 | 3rd party 제품 구매 필요 |
| **업그레이드** | 정기적인 Major · Minor 업그레이드 패치 | 요청에 따른 추가 개발 필요 |
