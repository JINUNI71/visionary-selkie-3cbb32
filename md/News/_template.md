# 1. 이 파일을 복사해 md/news/ 폴더에 "날짜-영문주소.md" 로 저장합니다.
#      예) 2026-10-02-genworks-rp-release.md  →  company/news/index.html#genworks-rp-release
#    목록에는 분류·제목·작성일이 한 줄로 보이고, 누르면 아래 본문이 펼쳐집니다.
#    이름이 _ 로 시작하는 파일(이 템플릿)은 페이지로 만들지 않습니다.
# 2. 아래 항목을 채우고, --- 아래에 본문을 마크다운으로 씁니다.
#    본문의 링크·이미지 경로는 사이트 루트 기준으로 씁니다. 예) products/genworks-rp.html
# 3. 터미널에서 ./build.sh 를 실행하면 목록 페이지가 만들어집니다.
#    (배포 없이 미리 보기만 하려면 python3 tools/build_news.py)
#
# title    필수. 목록 한 줄에 보이는 제목
# category 필수. 보도자료 또는 인사이트
# date     생략하면 파일 이름 앞의 날짜를 씁니다. 2026-10-02 형식
# summary  회사개요의 최신 소식과 검색 결과 설명에 쓰는 한두 문장. 생략하면 본문 첫 문단을 줄여 씁니다
# link     원문 주소. 넣으면 펼친 본문 아래에 "원문 바로가기 →" 버튼이 생깁니다 (새 창)
#          언론 보도·외부 기고처럼 원문이 따로 있을 때만 씁니다. https:// 로 시작
# link_label  버튼 글자를 바꾸고 싶을 때만. 예) 머니투데이 기사 보기
# slug     주소를 파일 이름과 다르게 하고 싶을 때만. 영문 소문자·숫자·하이픈
# cover    펼친 본문 맨 위 대표 이미지. assets/img/news/ 에 파일을 넣고 경로를 씁니다
# cover_alt  대표 이미지 설명 (화면 낭독기용)
# draft    true 로 두면 목록에서 빠집니다 (임시 저장)
