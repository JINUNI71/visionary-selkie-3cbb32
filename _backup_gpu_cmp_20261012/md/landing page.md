## Softworks Product Family

### 소프트웍스가 만든 제품군

인프라 가상화부터 GPU 워크로드, 보안 온톨로지까지. 구축· 운영 현장에서 검증된 기능을 제품으로 제공합니다.

#### 1. GenWorks (Resource Platform)

- GPU 클러스터 구축· 가상화· 공유· 관리. 대규모 GPU 자원을 워크로드에 맞게 나누고 운영합니다.

#### 2. GenWorks-K8s (Kubernetes Platform)

- K8s 클러스터 통합 관리. 여러 클러스터를 하나의 운영 체계 안에서 다룰 수 있게 합니다.

#### 3. GenWorks-ML (GPU Workload Management)

- GPU 자원 공유· 관리 플랫폼. 학습· 추론 워크로드의 자원 배분을 최적화합니다.

#### 4. OAP Security (Ontology Agent Platform)  ← 2026.10.07 SOP에서 명칭 변경

- 온톨로지 기반 보안 추론 에이전트. 위협과 자산의 관계를 구조화해 판단합니다.

#### 5. CloudV (Virtualization Management)

- 가상화 인프라 구축· 관리. 자원을 유연하게 배분하는 운영 기반을 제공합니다.
