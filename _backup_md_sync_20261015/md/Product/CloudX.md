## 02 Why Softworks

**소프트웍스가 CloudX를 다루는 방식**

### Why 01 — CloudX 공식 구축 파트너입니다

CloudX는 SK브로드밴드가 직접 개발·운영하는 서비스이며, 소프트웍스는 이 서비스를 고객 환경에 구축해 온 공식 파트너입니다. 제품을 유통하는 총판이 아니라 서비스 제공사와 함께 고객 환경을 설계하는 구축 조직입니다.

### Why 02 — 관리 포털을 직접 개발했습니다

SK브로드밴드 Cloud PC Admin 포털의 운영 및 고도화를 수행했습니다. CloudX는 Admin Portal의 고객별 Customizing을 지원하며, 해당 커스터마이징을 실제로 구현한 조직이 소프트웍스입니다. 외산 VDI는 하이퍼바이저 관리 도구 · 브로커 관리 도구 · 별도 포털을 오가며 운영해야 하지만, CloudX는 Admin Portal 한 화면에서 운영이 이루어집니다.

![단일 관리 도구 운영과 다중 도구 운영 방식의 비교](assets/cloudx/dia-cxportal.svg)
*단일 관리 도구 운영과 다중 도구 운영 방식의 비교*

### Why 03 — 공공 도입 요건을 제품과 절차 양쪽에서 충족합니다

제품은 국가정보원 보안기능확인서와 GS 인증 1등급을 보유하고, MSA·컨테이너·오토스케일링 등 정부 권고 Cloud Native 요건을 충족합니다. 도입 절차는 조달청 디지털서비스몰 MAS 계약으로 단축됩니다.

### Why 04 — 외산 VDI 라이선스 리스크의 현실적 대안을 설계합니다

사용자 그룹별로 외산 VDI와 CloudX를 병행·분리 배치하는 전환 시나리오를 설계합니다. 두 플랫폼을 모두 구축한 경험을 근거로 그룹별 배치 기준을 판단합니다.

## 04 Knowledge Base

**착수 전에 현황을 실측하고 산식으로 규모를 산정합니다**

VDI 전환의 성패는 착수 이전 단계에서 절반이 결정됩니다. 소프트웍스는 대형 전환 사업에서 설계 착수 전 수개월을 현황 파악에 투입하며, 그중 한 달가량은 실장비 PoC로 품질을 검증합니다. 근거 없이 산정한 규모는 이후 비용 초과나 성능 저하로 이어집니다.

| 지표 | 내용 |
|---|---|
| **실장비 PoC** | 관리·운영 서버와 스토리지를 실제로 구성해 검증 |
| **표준 사이징 설계** | 가상화 비율 · 여유율까지 근거 기록 |
| **공공 · 금융 · 의료** | 산업별 규제 요건 적용 이력 |
| **Admin Portal 개발** | 플랫폼 내부 구조까지 직접 다룬 경험 |

**축적된 자산**

- PoC 검증 항목 체크리스트 (서버 · 스토리지 · 네트워크 · 업무 호환성)
- 사용자당 네트워크 점유 대역폭 기준값 (약 200Kbps)
- VM 표준 사양 기준 (OS 디스크 70GB, Windows 11 업그레이드 고려)
- 체감 품질 기준선 (가상 PC 접속 20초 내외)
- 서버 대수 산정 산식 (동시접속 VM × 표준 사양 ÷ 서버 수용량)
- 가상화 비율 적용 기준과 CPU 여유율 확보 근거
- 스토리지 유효 용량 산정 (RAID · 중복제거 · 예비율 · 스냅샷)
- 망분리 환경 VDI Zone 배치 패턴
- 보안적합성 검증 절차 (착수 단계 편성)

## 05 Field Issues

| “외산 VDI 라이선스 비용이 통제되지 않습니다” | 매년 갱신 비용이 발생하는 외산 VDI 라이선스와 달리, CloudX는 한 번 도입으로 지속 소유하는 영구 라이선스(Perpetual License)를 제공합니다. 도입 후 해마다 누적되는 갱신 비용 부담을 획기적으로 줄여, 장기적인 인프라 운영 예산을 완벽하게 절감할 수 있습니다 |

| “공공 도입 절차가 복잡합니다” | 조달청 디지털서비스몰 MAS 계약(CLOUDX 2.0) 기반으로 도입 절차를 단축합니다 |

## 06 CloudX = VDI + 클라우드 인프라

![SK브로드밴드 로고](assets/cloudx/cloudx-logo.png)

## 07 CloudX 구성요소 — CloudX를 구성하는 여섯 개 구성요소

가상 PC 한 대가 안전하게 기동하기까지 포털, 인증, 브로커, 실행 노드가 순서대로 맞물려 작동합니다. 소프트웍스는 각 구성요소의 유기적인 동작을 완벽히 제어하며 다음과 같은 핵심 사항들을 철저하게 설계합니다.

### Admin Portal — 관리 업무 전체를 단일 포털에서 수행합니다

대시보드 · 사용자 정보관리 · 사용자 지원 · 포털 관리 · 정책 관리 · 서비스 관리 · 가상 PC 관리 · 테넌트 자원관리 · 템플릿 관리 · 시스템 자원관리 · 모니터링 통계 · 관리자 설정을 기본 제공합니다. Super Admin과 Tenant Admin으로 권한을 구분해 운영 책임을 분리할 수 있으며, 대시보드는 담당자별로 구성을 달리하는 위젯형입니다.

![12개 관리 메뉴와 Super Admin · Tenant Admin 권한 경계](assets/cloudx/dia-cxadmin.svg)
*12개 관리 메뉴와 Super Admin · Tenant Admin 권한 경계*

**소프트웍스가 하는 일** — 고객사 및 공공기관의 특수한 환경에 맞춰 기존 인사 시스템과의 계정 자동 동기화, 다중 인증(MFA/2차 인증) 연동은 물론, 기관 전용 특화 기능까지 완벽하게 개발 및 구축을 제공하며, 조직 구조에 최적화된 테넌트 관리자 권한 체계까지 섬세하게 설계합니다.

### User Portal — 브라우저 접속만으로 시작하는 스마트한 VDI 환경

포털 로그인만으로 가상 PC를 안전하게 실행할 수 있습니다. 사용자는 포털을 통해 가상 PC의 전원 제어와 함께 실시간 자원 사용량(CPU·메모리·디스크)을 자유롭게 확인할 수 있으며, 접속 클라이언트 및 사용 매뉴얼도 포털에서 손쉽게 다운로드할 수 있습니다.

![사용자 동선 5단계와 각 단계에서 관리자가 보유하는 통제 항목](assets/cloudx/dia-cxuser.svg)
*사용자 동선 5단계와 각 단계에서 관리자가 보유하는 통제 항목*

**소프트웍스가 하는 일** — 사용자가 직접 처리할 수 있는 제어 범위를 넓힐수록 IT 헬프데스크로 들어오는 단순 문의와 요청 업무가 크게 감소합니다. 소프트웍스는 기관의 운용 정책에 맞춰 사용자 자율 제어 범위, 가상 PC 전원 스케줄, 세션 타임아웃 방식을 최적의 수준으로 설계합니다.

### 접속 제어 계층 — 인증 경로와 화면 전송 경로의 완전 분리로 실현하는 강력한 보안

포털 로그인을 처리하는 인증 서비스와 자원을 배정하는 연결 브로커가 각자의 역할을 정밀하게 수행합니다. 가상 PC 접속은 세션 게이트웨이를 통해 이루어지며, 사용자 단말에는 암호화된 화면 출력 정보만 전송됩니다. VDI 환경에서는 중요한 데이터가 단말에 저장되지 않고 중앙 데이터센터 내에 안전하게 유지됩니다.

*접속 1회가 통과하는 인증 · 브로커 · 세션 게이트웨이 · 화면 전송 경로*

**소프트웍스가 하는 일** — 기관에서 기존에 사용 중인 인증 체계(SSO, 사내 계정 등)와 완벽하게 연동되며, 접속 환경에 따라 최적의 보안 정책을 적용합니다. 또한, 모든 접속 구간마다 촘촘한 보안 통제 지점을 지정하여 허가되지 않은 접근을 완벽히 차단합니다.

### 자원 운영 — 가상 PC를 사전 생성하고 사용 후 초기 상태로 복원합니다

단일 골든 이미지로 가상 PC를 생성하고, 사용이 종료되면 초기 상태로 복원합니다. 대기 풀은 임계값에 따라 자동으로 증감하므로 사용자는 생성 대기 없이 즉시 할당받습니다.

![임계값 기반 Scale Out / Scale In 자동 증설 및 회수 (임계값은 사업별 설정)](assets/cloudx/dia-cxscale.svg)
*임계값 기반 Scale Out / Scale In 자동 증설 및 회수 (임계값은 사업별 설정)*

**소프트웍스가 하는 일** — 출근 시간대에 사용자가 몰릴 때 가상 PC가 즉시 할당되지 않으면 접속 대기가 발생하고, 반대로 대기 수량을 너무 많이 잡아두면 시스템 자원이 낭비됩니다. 소프트웍스는 기관의 실제 사용자 접속 패턴을 정밀 분석하여 최적의 대기 수량(대기 풀)과 자동 확장 기준(임계값)을 설정합니다. 이를 통해 자원 낭비 없이, 출근 시간에도 대기 없는 쾌적한 접속 환경을 구현합니다.

### 이중화 구성 — 완벽한 이중화와 망분리로 구현하는 강력한 고가용성(HA)

소프트웍스가 제공하는 VDI 인프라는 모든 핵심 제어 계층을 이중화하여 장애 발생 시 즉시 정상 서버로 자동 전환됩니다. 또한 물리적 서버 장애 시에도 실행 중인 가상 PC가 자원이 충분한 다른 서버로 자동 이관되어 업무의 연속성을 완벽히 보장합니다. 이에 더해 서비스망, 관리망, 스토리지망을 물리적으로 철저히 분리하여 부하 간섭을 차단하고 보안 수준을 한층 강화했습니다.

![장애 발생 시 관리 계층 전환과 가상 PC 이관 동작](assets/cloudx/dia-cxha.svg)
*장애 발생 시 관리 계층 전환과 가상 PC 이관 동작*

**소프트웍스가 하는 일** — 이관을 수용할 예비 자원을 설계 단계에서 미리 확보합니다. 서버 한 대에 장애가 발생해도 잔여 서버가 수용할 수 있는 범위에서 가상화 비율을 정하는 것이 핵심입니다.

### 보안 정책 — 빈틈없는 보안, 관리자 맞춤형 정밀 정책 제어

관리자는 클립보드, 파일 전송, USB 포트 제어, 로컬 프린터 사용, URL 전달 등 다양한 보안 항목을 직관적으로 제어할 수 있습니다. 모든 통신 구간에는 기본적으로 데이터 암호화가 적용되며, 화면 캡처 시도 시 가상 PC 영역을 자동으로 가려주는 한편, 워터마크를 적용하여 차원 높은 정보 유출 방지 환경을 제공합니다.

![정책 제어 항목과 6개 보안 분야 대응](assets/cloudx/dia-cxsec.svg)
*정책 제어 항목과 6개 보안 분야 대응*

**소프트웍스가 하는 일** — 기관의 보안 규정 조항을 VDI 정책과 정밀하게 매핑하여 조직 및 그룹별 맞춤형 보안 통제를 제공합니다. 파일 반출입 시 전자결재/승인 절차를 거치도록 포털과 연계하여 무단 유출을 차단하며, 향후 보안 감사에 즉시 활용할 수 있는 증빙 산출물까지 체계적으로 제공합니다.

## 10 Operation & Support

**구축 완료 후에도 현장 지원이 이어집니다**

사업 종료 후 일정 기간 전담 인력이 현장에 상주해 안정화를 지원하고, 이후 하자보수 기간이 이어집니다. 장애는 상주 인력이 1차로 접수하고, 해결되지 않는 사안은 구축팀과 제조사 기술 조직으로 단계별로 이관됩니다.

- 안정화 기간 전담 인력 현장 상주
- 1 / 2 / 3차 단계별 장애 대응 체계
- 단일 창구 접수 후 상주 인력 1차 처리
- 장애 이력 DB 기록 및 점검 항목 환류
- 정기 예방 점검
- 관리 포털 운영 대행
- 사용자 계정·자원 관리
- Admin Portal 기능 고도화 개발
- 조달 재계약 지원
